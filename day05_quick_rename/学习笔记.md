# 第 1 周 Blender 侧学习笔记（Day 4-5）

## 一、环境设置

编辑 → 偏好设置 → 界面 → 显示：

- 开发者额外选项（Developer Extras）
- Python 工具提示（Python Tooltips）

开启后鼠标悬停任意按钮，提示框底部会显示对应的 `bpy.ops.xxx` API 名。

## 二、三大核心模块

| 模块 | 管什么 | 使用原则 |
|---|---|---|
| `bpy.data` | 场景里所有数据（物体、网格、材质等） | 读写数据优先用它，最稳定 |
| `bpy.context` | 当前状态（选中了什么、在哪个视图） | 获取当前操作对象 |
| `bpy.ops` | 所有"按钮操作"（添加物体、导入导出、渲染） | 依赖上下文，脚本里少用；导入导出只能用它 |

## 三、插件三件套

1. **Operator（OT_）**：干活的人
   - `bl_idname`：唯一调用名，小写带点，如 `object.quick_add_prefix`
   - `bl_label`：按钮显示文字
   - `bl_options = {'REGISTER', 'UNDO'}`：支持 Ctrl+Z
   - `bpy.props.StringProperty`：可按 F9 弹窗编辑的参数
   - `execute()` 必须返回 `{'FINISHED'}` 或 `{'CANCELLED'}`
2. **Panel（PT_）**：界面
   - `bl_space_type = 'VIEW_3D'`：挂在 3D 视图
   - `bl_region_type = 'UI'`：N 面板侧栏
   - `bl_category`：侧栏标签页名
   - `draw()` 每帧重画（即时模式，类似 Unity 的 OnGUI）
3. **register / unregister**：登记和注销
   - 注销时用 `reversed(classes)`，后注册的先注销
   - `if __name__ == "__main__": register()` 兼顾文本编辑器直接运行和正式安装两种场景

## 四、类名行规

- Operator 类：`OT_` 开头
- Panel 类：`PT_` 开头

## 五、测试结果

- N 面板出现 QuickR 标签和 Add Prefix 按钮
- 选中多个物体可批量加前缀
- F9 可修改 prefix 参数
- Ctrl+Z 可撤销
