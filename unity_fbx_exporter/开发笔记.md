## 文件分工

| 文件 | 职责 |
|---|---|
| `__init__.py` | bl_info、模块加载顺序 |
| `properties.py` | UnityFBXSettings（所有设置，挂在 Scene 上） |
| `exporter.py` | 纯导出逻辑，无 UI |
| `operators.py` | 导出、打开目录两个 Operator |
| `panel.py` | N 面板 UnityFBX 标签 |

## 关键 API 备忘

- 设置访问：`context.scene.unity_fbx_settings`
- 路径转绝对：`bpy.path.abspath(settings.export_path)`
- FBX 导出：`bpy.ops.export_scene.fbx(...)`（只能走 ops）
- Unity 参数：`axis_forward='-Z'`、`axis_up='Y'`

## 注册顺序

properties → exporter → operators → panel（反向注销）

## 测试场景

- 3 个独立物体（Cube、圆柱、带修改器物件）
- 2 个集合（含嵌套）
- 1 个名字带空格/特殊字符的物体
